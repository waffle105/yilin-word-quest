# 译林 2000 词闯关

面向江苏初中生的译林版英语词汇学习网页，现已部署在：

https://yilin-word-quest.vercel.app

## 主要功能

- 用户名直接进入，无需密码或注册；学习记录按用户名隔离
- 每次挑战前先预习单词、音标、释义和真人发音
- 按七上、七下、八上、八下、九上、九下及 Unit 生词顺序学习
- 音标学习模式：20 个元音、28 个辅音，可点击示范词跟读
- 拼写闯关、朗读自评、错词强化和间隔复习
- 三列表格默写，支持遮挡中文和批量核对
- 浏览器本地记录，并尝试与服务端同步

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

## 构建与部署

```bash
npm run build
```

仓库包含 `vercel.json` 和 `api/index.js`，可直接部署到 Vercel。构建输出目录为 `dist/client`。

## 数据说明

- `app/data/words.ts`：2000 词及基础音标、释义
- `app/data/curriculum.ts`：六册教材、44 个 Unit 的单词顺序映射
- 教材中可定位的词按首次出现的册次和 Unit 排列，其余课标补充词置于教材词之后

当前 Vercel 版本会将记录保存在用户浏览器中；若需要跨设备长期同步，应接入持久化云数据库。
